#启点起始页(起点指标)

>一个简约的浏览器起始页

---

##关于本项目

启点起始页是一个轻量、简洁的浏览器起始页。它没有复杂的功能堆砌，只做一件事——让你的新标签页清爽干净。

但清爽不等于简陋。每一个像素间距、每一次交互动效、每一帧过渡动画，都经过了反复推敲。你看到的简约，是无数细节堆叠后的克制。

---

##功能特性

- **搜索框**--支持Google/Bing/百度等多引擎一键切换，回车即搜
- **搜索历史**—— 自动记录搜索关键词，方便回溯
- **深色模式** —— 跟随系统自动切换，也可手动指定，夜间浏览不刺眼
- **背景定制** —— 支持纯色、渐变、用户本地上传图片、填写图片网址，打造属于你的起始页氛围
- **轻量极速** —— 零依赖，无框架，原生代码，加载速度毫秒级

---

##环境要求

- **PHP7.1-8.0**（推荐 7.4，8.0 以上未经测试）
-nginx/Apache/IIS均可

##部署

本项目必须部署在服务器上运行。

1.将代码上传至服务器目录
2.配置域名指向该项目根目录
3.访问域名即可使用
